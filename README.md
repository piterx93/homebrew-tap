# piterx93/tap

Homebrew formulae for [vilog](https://github.com/piterx93/vilog), a terminal log viewer for application logs.

```sh
brew install piterx93/tap/vilog
```

The formula builds vilog from source with Rust, on macOS and Linux. vilog was called jlv before 2.0; `brew upgrade` moves an installed jlv over.
