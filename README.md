# piterx93/tap

Homebrew formulae for [vilog](https://github.com/piterx93/vilog), a terminal log viewer for application logs.

```sh
brew install piterx93/tap/vilog
```

The formula builds vilog from source with Rust, on macOS and Linux. vilog was called jlv before 2.0. To move an installed jlv over, trust the tap once, then upgrade:

```sh
brew trust piterx93/tap
brew upgrade
```
